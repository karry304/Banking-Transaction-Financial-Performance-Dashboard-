# Banking-Transaction-Financial-Performance-Dashboard-
I built a Finance Analytics Dashboard in Power BI for a financial organization that wanted one place to track transaction performance. It covers five KPIs with year-over-year growth, plus monthly trends, success vs. failed transactions, customer segments, states, and gender split. I also created a transaction-type matrix to compare amount, fees, and tax, and a drill-down page for record-level detail. Users can filter by year, occupation, category, and a dynamic measure, which lets management find top segments and regions quickly and make better decisions.

Modeled complex banking transaction data to analyze total amount, fee structures, tax contributions, and regional performance.
Developed KPIs and DAX measures including Total Amount, Transactions, Fees, Tax, Previous Year (PY), YoY%, and Dynamic Metrics for financial performance tracking.
Built hierarchical drill-downs enabling seamless transition from executive-level KPIs to underlying record-level data.
Identified high-value customer segments, top-performing states, and high/low-contributing transaction categories using amount, volume, fees, and tax analysis.
